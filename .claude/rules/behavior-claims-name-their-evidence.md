# Claims Name Their Evidence

A count, coverage word or measured decision in a PR body, task note or session context states what was checked; reviewers read "all" as a guarantee.

- **A mutation count is the runner's sentence or nothing.** Quote `/crucible:mutation-check`'s sentence, or write no count and name the lines you reverted.
- **A claim names its reach tier.** A guarantee ("never…") is held to every way it can fail; best-effort lists what it misses. Inside the CLAUDE.md safety boundaries, everything is a guarantee.
- **A measured decision gets a guard**: a test that fails when the measurement stops holding, or a dated observation.
- **Coverage words name the forms** the tests exercise, instead of "every" and "all"; if the list can't be complete, say so. Correct a wrong claim where it was made.

*Source: tvforge — hand-written mutant counts over untested guards, 2 + 2 occurrences.*
