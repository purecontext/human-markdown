# Recall Before Research

Before investigating runtime behavior, API capabilities, or configuration by probing, web fetching, or trial and error, search recall first. A two-second search beats a five-minute probe, and it surfaces constraints a prior session already paid for.

## Triggers

- **Prior findings** — API behavior, runtime probes, config discoveries, error resolutions
- **Before recommending** — about to suggest an approach, library, or tool
- **Before pivoting** — changing approach because something didn't work (build failure, unexpected API behavior, runtime error). The wall you just hit may already be in recall.
- **Topic shift** — the work moves to a domain where prior sessions may have context

Skip it for the obviously novel: a first encounter with a codebase, greenfield design. The trigger is "this might have been figured out before."
